## 📌 Descripción

Este repositorio contiene el script de demostración conceptual del paradigma **Sinapsis Computacional**, desarrollado por el Instituto Doughel.

El paradigma propone que un sistema de inteligencia artificial puede adquirir y representar nuevos conocimientos **reconfigurando las relaciones entre un conjunto fijo de unidades de memoria estructural (Unidades DouSan)**, sin añadir nuevas unidades al sistema.

Este demo valida experimentalmente que es posible lograr un aprendizaje efectivo con un **crecimiento de huella de memoria del 0.00%**.

---

## 🎯 ¿Qué demuestra este script?

- Un corpus fijo de **1,000 Unidades DouSan** se reconfigura mediante un motor de matemática iterativa propietaria.
- El sistema pasa de representar un **Dominio A** (ej. Anatomía General) a un **Dominio B** (ej. Neuroanatomía Específica).
- El proceso se completa sin asignar memoria adicional en ningún momento.
- El resultado es convergencia estructural con métrica de alineación ≥ 0.999.
