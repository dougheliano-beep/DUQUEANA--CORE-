# 🔷 Persistencia Estructural de Primos Gemelos (IED/MREI)

Marco teórico y demo computacional para la Conjetura de los Primos Gemelos bajo el paradigma de **Inteligencia Estructural Duqueana (IED)**.

## 📚 Documentos
- 📄 `Primos_Gemelos_IED_MREI_Douglas_Urbina_Duque_2026.pdf` → Formalismo, conjetura y ruta de validación.
- 🐍 `twin_primes_verification_demo.py` → Interfaz pública de verificación estructural (demo blindado).
Este demo implementa la interfaz pública del operador MREI. El núcleo algorítmico completo está protegido como propiedad intelectual del Instituto Doughel y se distribuye bajo licencia restringida para nodos verificados.
