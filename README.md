## 🚀 ¿Qué es este proyecto?

El Ecosistema Duqueano es un marco científico que utiliza **geometría fractal pura** y **determinismo absoluto** para resolver problemas complejos. A diferencia de la IA tradicional, nuestro motor **MREI (Método de Resolución Estructural Iterada)** no requiere GPUs ni millones de datos: opera con ~6 KB de RAM, es 100% reproducible y cada resultado se certifica con criptografía (SHA-256).

## ⚡ Inicio Rápido (Quick Start)

Para probar la célula virtual determinista (Génesis) en tu propia máquina:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/dougheliano-beep/DUQUEANA--CORE-.git
   cd DUQUEANA--CORE-

   2. Ejecuta el verificador de prueba:
   ```bash
   cd verifier
   python3 run_verification.py
   ```
   El script ejecutará 10 vectores de prueba geométricos y te mostrará que la convergencia determinista coincide al 100%.
